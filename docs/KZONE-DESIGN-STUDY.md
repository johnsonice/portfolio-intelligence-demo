# K.zone 设计语言研究与 Portfolio Intelligence 应用

研究基于此前保存的 `kz1235/kzone-open` 源码，commit `fc636ac`（2026-09-14）。主要依据是 `DESIGN-LANGUAGE.md`、`cockpit/app-ui.css`、`studio-ui.css`、`reading-ui.css`、`browse-ui.css`、`settings-ui.css` 和 `tanfall-ui.css`。2026-09-23 重新访问 GitHub 返回 404，因此这里描述的是该快照，并不声称已核实线上最新版。

这是独立设计实验，分支为 `explore/kzone-design-language`，从 Portfolio Intelligence 的 `0f3cb95` 创建。原有亮蓝色版本和业务信息结构保留在原分支。

## 1. 核心意象

K.zone 将自己的视觉概括为“一张砂纸上的玻璃拼图”。七巧板 logo 是整套规范的几何来源：45° / 90° 方向、拼合严密、透光差异、细线折射边。

它更接近一个安静、可操作的个人工作台：视觉上的重点是内容、任务状态和操控位置。品牌识别来自材质与几何的重复，而不是大面积品牌色。

## 2. 设计元素清单

| 维度 | K.zone 的设计语言 | 本实验的应用 |
| --- | --- | --- |
| 基底 | 深炭灰 `#14161a`、暖灰 `#e9e7e3`；低透明度 SVG 颗粒 | 默认暖灰亮色，顶部可切换深色；轻颗粒不干扰正文 |
| 材质 | 磨砂玻璃、半透明面板、10–20px 模糊 | 首页卡片、工具按钮、对话气泡使用透明层；长报告采用较实的阅读底色 |
| 顶栏 | 平头纯色框、单条细线，没有装饰渐变 | 紧凑工具栏、克制的面包屑与状态区 |
| 结构线 | `--line` 用于边框、表格和分隔 | 所有页面共享边框 token |
| 受光线 | `--lit` 仅用于玻璃上缘 | 卡片和按钮只在上缘提亮 |
| 强调线 | `--edge` 用于 hover / focus | 悬停加深边线；键盘焦点保持清晰 |
| 几何 | 45° 切角，圆角不超过 4px | Review、Run、导航选中项、输入框和卡片使用切角 |
| 网格 | 8px 基础节奏；8 / 16 / 24px 间距 | 主要卡片、分区和工具区遵循该节奏 |
| 字体 | 系统无衬线正文；标签、数字、时间戳等宽 | 去掉大面积衬线标题；保留可读的正文尺寸；数值使用 tabular / mono |
| 标题标记 | 小号等宽、宽字距、`//` 前缀 | 首页 eyebrow、分区编号、报告章节使用相同语法 |
| 图标 | 线性 SVG，单色，细线，无 emoji | 沿用现有功能图标，统一灰阶与小尺寸，保留语义 |
| 状态 | 小三角、短标签、数量和局部颜色 | 模拟状态、任务状态与例外保留低饱和语义色 |
| 颜色 | 基础规范限灰阶 + 褪色绿 / 黄铜 / 暗红 | 普通交互去蓝；风险、正向与等待状态有色 |
| 数据图 | 实际源码扩展了锈蓝、苔绿等功能色 | 成本与收入分别使用灰蓝 / 苔绿；图例、数值同时保留 |
| 卡片 | 玻璃底、细边框、有限抬升 | 首页保留精简卡片与可展开 Preview；hover 最多上移 2px |
| 标签 | 方角、小号等宽、弱填充 | 公司、时间、版本和来源统一视觉层级 |
| 按钮 | 薄框、切角；按下下沉 1px | Review / Run 的目的仍清晰，不把每个按钮做成彩色块 |
| 对话 | 发出 / 接收不同切角，角色元信息较轻 | 用户消息采用切角玻璃块，agent 回答保持干净 |
| 输入区 | 输入框只容纳文字，附件和控制位于框外下方 | Workspace 输入与操作行在视觉上分离，输入始终可见 |
| 三栏布局 | 会话 / 工作内容 / 预览器，各区独立滚动 | 沿用 Tasks / Chat / Artifact 可调面板 |
| 拖动分隔 | 视觉 1px，实际命中区域更宽；拖动时亮起 | 保留现有拖拽、折叠和键盘调整，替换为中性细线 |
| 渐进披露 | 次级操作 hover 出现，详情展开，触屏仍可发现 | Preview、来源、工具和折叠内容保留明确入口 |
| 动效 | 0.15–0.2s 状态转换；运行呼吸灯，不放大或发光 | 轻过渡与下沉反馈；遵循 reduced-motion |
| 暗亮主题 | 变量双套、手动覆盖、系统偏好兜底 | 本实验提供 Light / Dark 两档，默认遵循此前确定的亮色偏好 |
| 手机适配 | 会话栏变抽屉，预览器变覆盖层，输入保持可达 | 保留当前 mock 的响应式抽屉及 Artifact / Chat 切换 |
| 空白态 | 少量说明 + 可开始的动作，不预先堆满信息 | Workspace 继续默认 New exploration |
| 角色选择 | 七巧板不同块映射不同角色，选择会持久化 | 本次只研究，不引入未经设计的 PE 多角色功能 |
| 实验内容 | 阅读、视频、七巧板游戏仍遵循同一材质体系 | 借鉴视觉一致性；不引入无关娱乐或媒体工作流 |

## 3. 规范与实现的差异

原始设计文档规定“只有三种状态色”，但较新的 `app-ui.css` 已为引擎、讨论和运行状态加入锈蓝、苔绿、黄铜、冷银、锈橙及淡紫。正确的理解是：避免装饰性色彩，每种颜色要有稳定用途，而不是机械地只允许三个色值。

文档中的 11px 等宽卡片标题适合高密度开发工具，直接照搬到 PE analytical report 会降低阅读性。本实验保留小号等宽的元信息，把业务标题和长段落维持在更易读的尺寸。

深色里的受光边比较强；亮色则通过纸色差和细边框提供层次。主题切换应改变材质参数，而不是简单反转所有颜色。

## 4. 页面映射

- **Home**：保留 To review / Suggested tasks。新增轻量编号与等宽元信息；玻璃切角卡片；主次动作更克制，Preview 仍只展开少量数据。
- **Workspace**：保留任务列表、聊天与 artifact 的可调布局。栏位使用细线分隔；聊天框的输入与操作分离；报告以纸张区域承载。
- **Cases / Review**：先阅读分析报告，再明确进入 Workspace。图表、证据、版本和公司范围保持一致。
- **Dashboard**：保留丰富的数据视图，统一成本与收入的灰蓝 / 苔绿图例；数值排版和表格线更整齐。
- **Routines / Sources**：统一卡片、状态标签、表格、展开项和设置控件，保持原有运行记录与来源追溯。
- **Scout**：保留用户选定的 08 积木机器人及拖动、悬浮输入和轻问答。输入和气泡使用同一玻璃材质。机器人本身作为有意保留的角色元素，不复制 K.zone 七巧板角色系统。

## 5. 本次不改变的产品含义

本次是视觉和交互表达实验。多公司数据范围、任务/会话、报告 artifact、Case、Routine 的关系不变；所有数据与 agent 运行仍为模拟。不会因换肤加入真实模型或连接器，也不会把浏览报告当作用户确认了结论。

设计文案保持面向 operating partner：review、compare、investigate、prepare。K.zone 的 engine、takeover、quota 等术语不直接搬进业务界面。

## 6. 如何比较

先在 Home 比较信息密度与辨识度，再打开同一个 Cedar / Northstar report；进入 Workspace 检查输入区、空白态与生成后的报告；最后在 Dashboard 检查图表可读性。右上角 Light / Dark 可切换两套材质，选择会保存在该演示的浏览器中。

重点观察：是否更像一个持续工作的分析工作台；长报告是否仍舒适；灰阶减少后动作是否仍清晰；机器人与界面是否协调。原版链接和原分支保留，用于直接比较。
